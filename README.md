# GameCentral

A simple, responsive gaming blog built with static HTML, CSS, and JavaScript. Designed with a dark gaming aesthetic, accessible navigation, and original content focused on guides, tips, facts, and recommendations.

## Features

- Responsive dark theme with green accents
- Home page, article listing, article detail, about, contact, and privacy pages
- Search and category filtering for gaming articles
- Original sample content for easy future updates
- No paid APIs, subscriptions, or heavy dependencies

## Run locally

Open `index.html` in a browser or serve the project with a simple static server.

Example:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000
